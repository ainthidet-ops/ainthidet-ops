# School Media

ระบบบริหารสื่อและเทคโนโลยีโรงเรียน
ผู้พัฒนาระบบ: ครูกฤษฎา อินธิเดช

## เผยแพร่ด้วย GitHub Pages
1. สร้าง repository ชื่อ school-media
2. อัปโหลด index.html, app.js, styles.css และโฟลเดอร์ assets ไปที่ระดับแรกของ repository
3. ไปที่ Settings > Pages
4. Source: Deploy from a branch
5. Branch: main, Folder: / (root), กด Save
6. เปิดลิงก์เว็บไซต์ที่ GitHub Pages แสดง

## ขอบเขตระบบ
- GitHub Pages ให้บริการเว็บไซต์แบบสาธารณะ ระบบลงชื่อเข้าใช้ ChatGPT ของโฮสต์เดิมจะไม่ติดไปด้วย
- ข้อมูลใหม่เก็บในเบราว์เซอร์ของผู้ใช้ ไม่ซิงก์ Google Sheets หรือข้ามเครื่องอัตโนมัติ
- ไฟล์ชุดนี้ไม่มีข้อมูลรายการใช้งานเดิมหรือรหัสผ่าน
- ที่อยู่ Google Drive ในหน้าเว็บเป็นลิงก์ไปยังโฟลเดอร์ของเจ้าของระบบ การเข้าถึงยังขึ้นกับสิทธิ์ของ Google Drive
