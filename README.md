# ระบบบริหารสื่อและเทคโนโลยีโรงเรียน
ผู้พัฒนาระบบ: **ครูกฤษฎา อินธิเดช**

## เข้าใช้งาน
เปิด https://ainthidet-ops.github.io/ainthidet-ops/ แล้วเลือก **เข้าสู่ระบบฐานข้อมูลกลาง**

ระบบกลาง: https://script.google.com/macros/s/AKfycbwaB3KIoLHwffMDI3dN6mPZG7gOxUEqqUvVTpWsLIZpjancgneMMUw5rghf428R9Eu5/exec

ผู้มีลิงก์สามารถดู เพิ่ม และแก้ไขข้อมูลผ่านเว็บได้โดยไม่ต้องลงชื่อเข้าใช้ ตามที่เจ้าของระบบอนุญาต ไฟล์ Google Sheets ไม่ได้เปิดสิทธิ์โดยตรงให้บุคคลทั่วไป

## โครงสร้าง
- GitHub Pages เป็นทางเข้าสู่ระบบกลางและเครื่องมือสำรองข้อมูลเดิมในเบราว์เซอร์
- Google Apps Script ให้บริการหน้าเว็บและรับส่งข้อมูลกับ Google Sheets
- `app.js`, `styles.css`, `index.html`, `assets/` เป็นไฟล์หน้า GitHub Pages
- `school-media-shared-source.zip` เป็นซอร์สสำหรับติดตั้ง Apps Script ไม่ใช่ไฟล์ข้อมูลใช้งานจริง และไม่ต้องนำ Index.html ใน ZIP มาแทน index.html ของ GitHub Pages

## ข้อมูลร่วมกัน
ข้อมูลใหม่ต้องบันทึกในหน้าระบบกลาง ระบบยืนยันสำเร็จหลังเซิร์ฟเวอร์บันทึกแล้ว และตรวจข้อมูลใหม่ทุก 10 วินาทีเมื่อไม่ได้เปิดแบบฟอร์ม มีการป้องกันเขียนทับเมื่อมีการแก้ไขพร้อมกัน

หน้าทะเบียนอาคารและห้องมีสรุปจำนวน Smart TV และ Projector แยกตามอาคาร โดยรวมจำนวนจากทะเบียนของทุกห้อง

## สำรองและนำเข้าข้อมูล
ข้อมูลเก่าที่เคยกรอกบนเว็บ GitHub อยู่ในพื้นที่จัดเก็บของเบราว์เซอร์เดิม ใช้ปุ่มสำรองข้อมูลเดิมเพื่อดาวน์โหลดหรือคัดลอก JSON แล้วนำเข้าในหน้าระบบกลาง
ข้อมูลเดิม 53 แบบสำรวจยังไม่ได้กู้คืนจากต้นทาง ห้ามใช้ไฟล์ JSON ว่างแทนข้อมูลที่สูญหาย

การนำเข้ารองรับ JSON รุ่น 2 ยังไม่รองรับ Excel โดยตรง ข้อมูลย้อนหลังใช้วันที่สำรวจจริงและจัดปีงบประมาณตั้งแต่ 2565 โดยอัตโนมัติ

## หากเข้าไม่ได้
ใช้ Chrome หรือ Safari โดยตรง หากลงชื่อเข้าใช้หลายบัญชี ให้ทดลองหน้าต่างไม่ระบุตัวตนและลงชื่อเข้าใช้เพียงบัญชีเดียว หลีกเลี่ยงเบราว์เซอร์ใน Messenger/LINE สำหรับขั้นตอนลงชื่อเข้าใช้และดาวน์โหลด
อ้างอิง Google: https://developers.google.com/apps-script/guides/support/troubleshooting
